# Правила для агентов (Grok, Cursor)

Эти правила обязательны в сессиях, которые меняют репозиторий Bell.
Процесс для людей — в [`CONTRIBUTING.md`](CONTRIBUTING.md).

## Одна единица работы

Один сеанс = один Issue = одна ветка = один PR.

Не подмешивайте соседние задачи. Не открывайте второй PR из той же сессии.

## Файлы и объём

- Не переносите и не переименовывайте файлы, если Issue явно не про раскладку каталогов.
- Не начинайте крупный рефакторинг, которого нет в назначенном Issue.
- Физика одного элемента со временем должна стать одной generic-функцией. Пока Issue этого не требует — не начинайте такую перепись.
- Оба движка остаются: DiffAlgebra (DA) и Lie-путь на TaylorSeries. Не удаляйте ни один.
- Предпочитайте multiple dispatch цепочкам `isa`.
- Не записывайте историю версий в комментарии исходников.

## Проверки, версия, журнал

- Перед коммитом всегда запускайте тесты:

  ```text
  julia --project=. -e "using Pkg; Pkg.test()"
  ```

- Не повышайте `version` в `Project.toml`, если Issue не является релизом.
- Пользовательские изменения записывайте в `CHANGELOG.md`, секция `[Unreleased]`.

## Язык

Пользовательскую документацию этого репозитория пишите по-русски.
Технические имена (типы, функции, файлы, conventional commits) оставляйте на английском.
Отвечайте по-русски, когда пишете такие документы или объясняете изменение человеку.
