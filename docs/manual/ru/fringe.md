# Краевые поля диполей и квадруполей

Гамильтониан тела магнита предполагает поле, которое включается и выключается
скачком на торцах. Реальное поле нарастает на расстоянии порядка зазора.
Краевую область описывают отдельными тонкими отображениями на входе и на
выходе магнита; отображение тела не меняется. Решётка хранит физическое
описание магнита: длину, угол поворота, углы полюсных торцов ``e_1, e_2``,
полный зазор ``g`` и краевой интеграл ``K``. Модель края выбирают, когда
строят отображение кольца.

## Жёсткий край, линейный порядок

Если полюсный торец повёрнут на ``e``, граница поля не перпендикулярна
опорной орбите. Лишний (или недостающий) треугольник поля действует как тонкая
линза

```math
\Delta p_x = h\tan e\;x,\qquad \Delta p_y = -h\tan\psi\;y,
\qquad \psi = e - h g K\,\frac{1+\sin^2 e}{\cos e},
```

где ``h = 1/\rho``. Поправка ``\psi - e`` происходит от конечной протяжённости
края: внутри него орбита уже изгибается, поэтому угол между орбитой и границей
поля меняется. Для секторного магнита с ``e = 0`` и ``K = 0`` линейное краевое
отображение есть тождество.

## Жёсткий край, нелинейный

Вертикальный толчок зависит от угла между траекторией частицы и границей поля,
а не от угла опорной орбиты. При наклоне ``x' = p_x/p_s``,
``p_s = \sqrt{(1+\delta)^2-p_x^2-p_y^2}``, эффективный угол есть ``e + x'``
на входе и ``e - x'`` на выходе. Край — преобразование Ли ``\exp(-:K:)`` с генератором

```math
K_{\rm in} = -\frac{h\tan e}{2}\,x^2 + \frac{h}{2}\,y^2\,\tan\!\left(\psi + \arctan x'\right),
\qquad
K_{\rm out} = -\frac{h\tan e}{2}\,x^2 + \frac{h}{2}\,y^2\,\tan\!\left(\psi - \arctan x'\right).
```

Поскольку край порождён одним многочленом ``K``, отображение симплектично
во всех порядках. При ``e = 0`` ведущий член есть
``K = \pm h\,y^2 p_x/(2 p_s)``. На дисперсионной орбите ``p_x = D'\delta``,
поэтому вертикальная фокусировка каждого края меняется линейно с ``\delta``:
края дают вклад в вертикальную хроматичность даже тогда, когда их линейный
эффект исчезает. Тот же член следует из продольного поля
``B_s = y\,\partial_s B_y`` ступенчатого профиля.

У квадруполей ведущий эффект жёсткого края имеет в генераторе четвёртую степень,

```math
K = \pm\frac{k_1}{12(1+\delta)}\left(x^3 p_x + 3 x y^2 p_x - 3 x^2 y p_y - y^3 p_y\right),
```

(``+`` вход, ``-`` выход). Он меняет зависящий от амплитуды сдвиг частоты
и оставляет частоты и хроматичность первого порядка без изменения.

## Мягкий край

Поле на опорной орбите есть ``B_y = B_0 F(z)`` с профилем ``F``, который
растёт от 0 снаружи до 1 внутри. Эффективная граница поля при ``z = 0``
фиксирована равенством площадей,

```math
\int_{-W}^{0} F\,dz = \int_{0}^{W} (1-F)\,dz,
```

так что интеграл поля и угол поворота — те же, что у магнита с жёстким краем.
Краевой интеграл ``gK = \int F(1-F)\,dz``. Профили:

* Энга: ``F = 1/\left(1+\exp P(-z/g)\right)``, ``P`` — многочлен;
* гиперболический тангенс: ``F = \tfrac12\left(1+\tanh(z/\lambda)\right)``, ``gK = \lambda/2``;
* линейный скат ширины ``w``: ``gK = w/6``;
* табулированный профиль карты поля, интерполированный и нормированный.

Мягкая область ``[-W, W]`` заменяет последнюю длину ``W`` дрейфа и первую
длину ``W`` тела в раскладке жёсткого края. Полная длина и угол поворота сохраняются.

### Гамильтониан в крае

В системе Френе орбиты, которая следует локальному полю, ``h(s) = h_0 F(s)``,

```math
H = e(\delta) - (1+hx)\sqrt{(1+\delta)^2 - (p_x - a_x)^2 - p_y^2}
    + h x + \frac{h^2x^2}{2}
    + \frac{b_1}{2}(x^2-y^2) + \frac{b_2}{6}(x^3-3xy^2) + h\,b_1\Big(\frac{x^3}{3} - \frac{xy^2}{2}\Big),
\qquad a_x = -\frac{y^2 h_0 F'(s)}{2(1+hx)} .
```

Векторный потенциал ``a_x`` даёт продольное поле ``B_s = y\,b'/(1+hx)`` и
вертикальную зависимость второго порядка
``B_y = b - \tfrac{y^2}{2}\left[b''/(1+hx)^2 - b'h'x/(1+hx)^3\right]``;
вместе они удовлетворяют ``\nabla\times B = 0`` до второго порядка по ``y``.

Граница поля — прямая, перпендикулярная свободной от поля орбите, а система
отсчёта следует кривой орбите. Точка с поперечным положением ``x`` видит профиль
при ``z = s + x\,\theta(s)``, где ``\theta`` — угол между локальной орбитой и
свободной от поля орбитой: ``\theta = h_0\int_{-W}^{s}F`` на входе и
``\theta = -h_0\int_{s}^{W}F`` на выходе. Разложение по ``x`` даёт градиент
``b_1 = h_0F'\theta`` и секступолеподобный член ``b_2 = h_0F''\theta^2``.
Интеграл градиента

```math
\int b_1\,ds = h_0^2\int F(1-F)\,dz = h_0^2\,gK
```

есть вертикальная фокусировка поправки ``\psi`` выше; в горизонтальной плоскости
он гасит дефицит слабой фокусировки ``h_0^2\int (F^2-\Theta)\,dz = -h_0^2 gK``
укороченного поля. Мягкий край поэтому воспроизводит линейную модель жёсткого
края с краевым интегралом своего профиля, а его нелинейные члены стремятся к
нелинейному жёсткому краю при ``g\to 0``.

### Интегрирование через край

Гамильтониан зависит от ``s``. Три метода дают отображение области:

* **Расщепление**: ``n`` слоёв, в которых ``F, F', F''`` заменены значениями слоя; каждый слой есть ``\exp(-\Delta s :H_k:)``. Второй порядок — один шаг на слой, четвёртый — композиция Ёсиды ``w_1 = 1/(2-2^{1/3})``, ``w_0 = 1-2w_1``. Каждый слой — преобразование Ли, поэтому отображение симплектично.
* **Разложение Магнуса**: на каждом подинтервале ``\exp(-:\Omega:)`` с ``\Omega = \Delta s\,H(s_m)`` (второй порядок) или, с двумя узлами Гаусса, форма четвёртого порядка ниже. Симплектично.
* **Интегрирование Тейлора**: уравнения движения в обрезанных степенных рядах (дифференциальная алгебра) с делением шага, пока отображение не меняется меньше допуска. По построению не симплектично; дефект порядка допуска.

Шаг Магнуса четвёртого порядка (``H_1, H_2`` в узлах Гаусса ``s_m \mp \Delta s\sqrt3/6``, сначала ``H_1``):

```math
\Omega = \frac{\Delta s}{2}(H_1+H_2) - \frac{\sqrt3}{12}\Delta s^2\,[H_1,H_2] .
```

Для профилей с изломами (линейный скат, таблица) производные берут как средние
по слою или шагу, что сохраняет ``\int F'`` и ``\int F''`` точными.

## Проверки

* Без края отображение кольца совпадает с голой решёткой.
* При ``g\to 0`` частоты и хроматичности мягкого края приближаются к нелинейному жёсткому краю линейно по ``g``.
* Линейная фокусировка мягкого края равна фокусировке жёсткого края с ``K = \int F(1-F)dz/g``.
* Разные методы и профили с одним краевым интегралом согласуются с точностью нарезки.
* ``J^{\mathsf T} S J = S`` для краевых отображений до ошибки округления (методы Ли).

## Приближения

* В градиентном члене ``b_1, b_2`` краевую область считают прямой; поправки порядка ``h_0^2 g^2`` не включены.
* Смещение между опорными орбитами мягкого и жёсткого края (порядка ``h_0 g^2``) поглощено системами отсчёта; строят только отображения около опоры.
* Поворот полюсного торца на мягком крае — линейный клин на эффективной границе; зависимость профиля от ``x\tan e`` дальше не разлагают.
* Поля разложены до второго порядка по ``y``; мягкие края квадруполей не моделируются.

## Метрика криволинейной системы

В криволинейной системе сила несёт множитель ``(1+hx)``, поэтому градиентный член даёт ``h b_1 x^2`` (горизонтально) и ``h b_1 xy`` (вертикально). Поскольку ``\int h b_1\,\mathrm{d}s = -\tfrac12\int b_2\,\mathrm{d}s`` (``\theta' = h_0 F``), горизонтальный секступолеподобный член прямой эффективной границы сокращается, а вертикальный равен ``b_2/2``. Гамильтониан тела вместе с краем хранит этот метрический член, так что сокращение есть часть модели, а не поправка, наложенная потом.
