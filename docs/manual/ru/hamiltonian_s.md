# ``s``-гамильтониан

Физика элемента — скаляр ``H(z,s)``. Векторное поле не пишут первым и затем не подгоняют под гамильтониан. Оно есть ``\mathrm{d}z/\mathrm{d}s=S\nabla H``.

## От ``(t,-E)`` к ``(l,\delta)``

На прямой опорной оси пары ``(x,P_x)``, ``(y,P_y)`` и ``(t,-E)`` каноничны, а порождающая движения по ``s`` — минус продольный кинетический импульс минус заряд, умноженный на ``A_s``:

```math
\mathcal{H}
=-\sqrt{E^2/c^2-m^2c^2-(P_x-ZeA_x)^2-(P_y-ZeA_y)^2}-ZeA_s.
```

Время отсчитывают от опорной частицы, ``\Delta t=t-t_0(s)``, импульсы делят на ``p_0``. Производящая функция второго рода

```math
F_2(t,P;s)=-p_0 c\,P\,\bigl(t-t_0(s)\bigr)
```

даёт новую координату ``q=-c\,\Delta t`` и новый импульс ``P=E/(p_0 c)`` и добавляет к гамильтониану ``P/\beta_0``. После деления на ``p_0``

```math
H=\frac{P}{\beta_0}
-\sqrt{P^2-\frac{1}{\beta_0^2\gamma_0^2}-(p_x-a_x)^2-(p_y-a_y)^2}-a_s,
```

где ``a_i=(Ze/p_0)A_i`` и ``p_{x,y}=P_{x,y}/p_0``.

Отклонение импульса ``\delta=(p-p_0)/p_0`` заменяет энергетическую координату ``P``. Безразмерная энергия

```math
\mathcal{E}(\delta)=\sqrt{(1+\delta)^2+\frac{1}{\beta_0^2\gamma_0^2}}=\frac{E}{p_0 c},
\qquad \mathcal{E}(0)=\frac{1}{\beta_0}.
```

Точечное преобразование, порождённое ``F_2(q,\delta)=q\,\mathcal{E}(\delta)``, есть

```math
P=\mathcal{E}(\delta),\qquad
l=q\,\frac{\mathrm{d}\mathcal{E}}{\mathrm{d}\delta}=q\,\beta(\delta)=-v\,\Delta t.
```

Поскольку эта ``F_2`` не зависит от ``s``, значение ``H`` не меняется: подставляют ``P=\mathcal{E}(\delta)`` и ``q=l/\beta(\delta)``. Так как ``P^2-1/(\beta_0^2\gamma_0^2)=(1+\delta)^2``,

```math
H=\frac{\mathcal{E}(\delta)}{\beta_0}-p_s-a_s,\qquad
p_s=\sqrt{(1+\delta)^2-(p_x-a_x)^2-(p_y-a_y)^2}.
```

## Энергетический член

``\mathcal{E}(0)/\beta_0=1/\beta_0^2`` — несущественная константа. Вычитая её, получают продольный член, которым пользуются все магнитные элементы и толстый резонатор:

```math
\mathrm{energy\_term}(\delta)
=\frac{1}{\beta_0}\sqrt{(1+\delta)^2+\frac{1}{\beta_0^2\gamma_0^2}}-\frac{1}{\beta_0^2}.
```

На опорной орбите ``\mathrm{energy\_term}(0)=0``. Это не кинетическая энергия. Дифференцирование под корнем даёт тождество, которое фиксирует знак ``l``:

```math
\frac{\partial\,\mathrm{energy\_term}}{\partial\delta}=\frac{v(\delta)}{v_0}.
```

Проверка на дрейфе (``a=0``), на оси (``p_s=1+\delta``):

```math
\frac{\mathrm{d}l}{\mathrm{d}s}
=\frac{\partial H}{\partial\delta}
=\frac{v}{v_0}-1.
```

То же следует из ``l=-v\Delta t`` и ``\mathrm{d}(\Delta t)/\mathrm{d}s=1/v-1/v_0``, если ``v`` вдоль дрейфа постоянна. Формула вычисляется одним и тем же выражением на числах, на многочлене Тейлора и на числе дифференциальной алгебры.

Кривизну и векторный потенциал каждого элемента добавляют в главе [Гамильтонианы элементов](hamiltonians.md). Константу и линейный кусок снимают только тогда, когда ``H`` хранят как многочлен пути Ли; оставшийся линейный кусок означает, что опорная орбита не есть решение.
