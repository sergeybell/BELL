# Движение в ВЧ

Гамильтониан резонатора выведен в главе [Гамильтонианы элементов](hamiltonians.md). Здесь — движение, которое из него следует: уравнения на оси, отображение за оборот и синхротронная частота. Гладкое среднее по кольцу — глава [Продольное движение](longitudinal.md). Меняющийся опорный импульс — глава [Ускорение](acceleration.md).

## Уравнения на оси

На оси ``p_s=1+\delta``, и толстый однородный зазор длины ``L`` имеет

```math
H(l,\delta)=\mathrm{energy\_term}(\delta)-(1+\delta)
+\frac{ZV}{p_0 c\,k L}\cos\varphi,
\qquad
\varphi=\varphi_s+\frac{k\,l}{\beta(\delta)},
\qquad
k=\frac{2\pi h\beta_0}{C}.
```

Уравнения Гамильтона: ``\mathrm{d}l/\mathrm{d}s=\partial H/\partial\delta`` и ``\mathrm{d}\delta/\mathrm{d}s=-\partial H/\partial l``.

Энергетический член даёт ``v/v_0``. Член ``-(1+\delta)`` даёт ``-1``. ВЧ-член зависит от ``\delta`` только через ``\beta(\delta)`` в фазе. При

```math
\frac{\mathrm{d}\beta}{\mathrm{d}\delta}=\frac{\beta}{(1+\delta)\gamma^2}
```

пара такова:

```math
\begin{aligned}
\frac{\mathrm{d}l}{\mathrm{d}s}
&=\frac{\beta(\delta)}{\beta_0}-1
+\frac{ZV}{p_0 c\,L}\,\frac{l\sin\varphi}{\beta\,(1+\delta)\,\gamma^2},\\[2pt]
\frac{\mathrm{d}\delta}{\mathrm{d}s}
&=\frac{ZV}{p_0 c\,L}\,\frac{\sin\varphi}{\beta(\delta)}.
\end{aligned}
```

Второе уравнение есть ``\mathrm{d}p/\mathrm{d}s=(1/v)\,\mathrm{d}E/\mathrm{d}s`` при ``\mathrm{d}E/\mathrm{d}s=ZV\sin\varphi/L``. Первый член ``\mathrm{d}l/\mathrm{d}s`` — дрейф: более быстрая частица уходит вперёд. Последний член есть потому, что ``l=-v\Delta t`` содержит собственную скорость частицы. Когда поле меняет ``v``, меняется и ``l``, даже при фиксированном ``\Delta t``. В переменных ниже, где координата — само запаздывание, этого члена нет.

## Фаза и отклонение энергии

```math
\varphi=\varphi_s+\frac{2\pi h}{C}\frac{\beta_0}{\beta(\delta)}\,l,
\qquad
\Delta E=E-E_0=p_0 c\Big(\mathcal{E}(\delta)-\frac{1}{\beta_0}\Big).
```

Пара ``(\varphi,\Delta E)`` есть пара ``(q,P)`` с точностью до постоянных множителей, поэтому она канонична с точностью до постоянного множителя ``k\,p_0 c`` при гамильтониане. На оси

```math
\frac{\mathrm{d}\varphi}{\mathrm{d}s}
=\frac{2\pi h}{C}\Big(1-\frac{\beta_0}{\beta(\delta)}\Big),
\qquad
\frac{\mathrm{d}(\Delta E)}{\mathrm{d}s}
=\frac{ZV}{L}\sin\varphi.
```

Энергетический толчок дальнейшего пересчёта не требует. Нелинейность ``\delta(\Delta E)`` сидит в уравнении фазы. В ``(l,\delta)`` нелинеен сам толчок.

## Один оборот

За частицей следят раз за оборот, на фиксированном азимуте. Отображение за оборот — композиция всех элементов. При одном тонком резонаторе и без ускорения (``\sin\varphi_s=0`` или ``ZV\sin\varphi_s`` в точности гасит постоянные потери) на каждом обороте применяется одно и то же отображение. Кольцо автономно: замкнутая орбита, частоты, нормальная форма и бакет — свойства этого одного отображения.

Без разложения в ряд тонкий толчок — отображение из главы [Гамильтонианы элементов](hamiltonians.md), а остальное кольцо меняет приход через время пролёта ``T(\delta)``:

```math
\begin{aligned}
\mathcal{E}_{n+1}&=\mathcal{E}(\delta_n)+\frac{ZV}{p_0 c}S_n,\\
\delta_{n+1}&=\sqrt{\mathcal{E}_{n+1}^2-1/(\beta_0^2\gamma_0^2)}-1,\\
l_{n+1}&=\frac{\beta_{n+1}}{\beta_n}\,l_n
-C_0\frac{\beta_{n+1}}{\beta_0}\Big(\frac{T_{n+1}}{T_0}-1\Big),
\end{aligned}
```

где ``S_n=\sin\varphi_n-\sin\varphi_s``. Первый кусок ``l_{n+1}`` пересчитывает ``l=\beta q`` при фиксированном ``\Delta t``. Второй — проскальзывание по кольцу.

В первом порядке по ``(\delta,l)``, с линейным проскальзыванием ``\eta_0`` из главы [Чтения отображения за оборот](map_readings.md),

```math
\delta_{n+1}=\delta_n+\mathcal{V}\,S_n,
\qquad
l_{n+1}=l_n-C_0\eta_0\,\delta_{n+1},
\qquad
\mathcal{V}=\frac{ZV}{\beta_0^2 E_0}.
```

Квадратичное проскальзывание ``\eta_1`` входит в следующем порядке, в ``T/T_0-1=\eta_0\delta+\eta_1\delta^2+\cdots``. Коэффициент при ``\delta^2`` зависит от того, координата ли это ``l``, ``\delta`` или ``\Delta E``. Корень ``T(\delta)=T_0`` от этого не зависит.

## Синхротронная частота

Линеаризуем отображение за оборот: тонкий резонатор и кольцо, которое за оборот сдвигает ``\Delta l=-\eta_0 C_0\delta``. Толчок и след дают

```math
\cos 2\pi Q_s
=1-\frac{2\pi h\,\eta_0\,ZV\cos\varphi_s}{2\beta_0^2 E_0}.
```

При малом ``Q_s``

```math
Q_s=\sqrt{\frac{h\,\eta_0\,ZV\cos\varphi_s}{2\pi\beta_0^2 E_0}},
\qquad
\eta_0=\alpha_0-\frac{1}{\gamma_0^2}.
```

Устойчивость начала требует ``\eta_0\cos\varphi_s>0``. Выше критической энергии в этом синусном соглашении ``\varphi_s=0``; ниже — ``\varphi_s=\pi``. Сравнение ``Q_s`` по следу продольного блока с этим корнем проверяет знак и нормировку ``H_{\mathrm{rf}}``. Они различаются членом порядка ``Q_s^2``.

Толстый резонатор внутри трекера этим толчком не заменяют. Поток интегрирует ``H`` по ``L``. Формула частоты — тонкое чтение того же ``H`` при одном толчке за оборот.
