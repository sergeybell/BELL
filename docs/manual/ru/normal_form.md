# Нормальная форма и равновесный импульс

## Нормальная форма фактора оборота

Линейную часть ``R`` фактора оборота приводят к трём вращениям симплектической матрицей ``A``, ``A^{\mathsf T}SA=S``. Генераторы в нормальных координатах ``w=A^{-1}z`` — это обратные образы ``f(Aw)``.

Вращение действует на комплексный моном
``h_{\mathbf{j}\mathbf{n}}=\prod_k(q_k+ip_k)^{j_k}(q_k-ip_k)^{n_k}``
фазой ``e^{-i(\mathbf{j}-\mathbf{n})\cdot\boldsymbol{\mu}}``. Гомологический оператор на генераторе — делитель

```math
F-F\circ r(\mu),\qquad
F_{\mathbf{j}\mathbf{n}}
=\frac{-f_{\mathbf{j}\mathbf{n}}}{1-e^{-i(\mathbf{j}-\mathbf{n})\cdot\boldsymbol{\mu}}}.
```

В степени 3 равенство ``\mathbf{j}=\mathbf{n}`` невозможно, поэтому в отсутствие резонанса третьего порядка весь кубический генератор снимается. В степени 4 ядро — линейная оболочка произведений действий. Эти члены остаются гамильтонианом нормальной формы ``h_4=\sum_{i\le j}c_{ij}J_i J_j``. Кубическое сопряжение вносит ``\tfrac12[f_3,F_3]`` в квартический генератор до этого шага.

Гомологический оператор применяют к генераторам. Сопряжением полного полиномиального отображения нормальную форму не строят. То же извлечение генераторов из полиномиального отображения, которое не родилось фактором Ли, — шаг Драгта–Финна в главе [Факторы Ли и дифференциальная алгебра](lie_and_da.md).

## Тор

После нормальной формы есть три амплитуды ``J_x,J_y,J_s`` и три фазы. Тор этих действий — множество всех троек фаз при этих фиксированных амплитудах: три окружности, а не траектория и не список оборотов.

Один оборот прибавляет к фазам постоянные углы и не меняет амплитуды. Лабораторное ``\delta`` — функция трёх фаз. Равновесный импульс — среднее этой функции по всему тору сразу. Куски, нечётные по фазам, усредняются в нуль. Остаётся линейная по действиям форма

```math
\delta_{\mathrm{eq}}=\delta^\ast+d_x J_x+d_y J_y+d_s J_s.
```

Для тонкого ВЧ на стационарной сепаратрисе ``\delta^\ast`` есть численный нуль. Кубическая поправка ВЧ по ``\hat\varphi^2`` имеет степень ``J^2`` и не сохраняется.

Длинное среднее по слежению совпадает с этим средним по тору, когда частоты несоизмеримы. Слежение тор не строит.

## Формула проскальзывания как подгонка этого среднего

Частица, колеблющаяся в стационарном ВЧ-бакете (``\varphi_s=\pi``, ниже критической энергии), не имеет нулевого среднего относительного импульса. Фаза ВЧ возвращается к себе за синхротронный период только если среднее время пролёта совпадает с периодом ВЧ. При нелинейном факторе проскальзывания это условие фиксирует

```math
\delta_{\mathrm{eq}}
=-\frac{\eta_1\langle\delta^2\rangle+\Lambda}{\eta_0},\qquad
\Lambda=-\frac{2\pi}{C}\bigl(J_x\xi_x+J_y\xi_y\bigr).
```

Здесь ``\eta_0,\eta_1`` — коэффициенты проскальзывания времени пролёта из главы [Чтения отображения за оборот](map_readings.md), ``\xi_{x,y}`` — линейные хроматичности, ``J_{x,y}`` — действия Курранта–Снайдера. Для линейного синхротронного колебания ``\langle\delta^2\rangle=\delta_m^2/2``. Кубическое обрезание формы ВЧ умножает кусок ``\eta_1`` на ``1-\hat\varphi^2/32`` и сдвигает синхротронную частоту на ``\Omega/\omega_s=1-\hat\varphi^2/16``. Эта поправка второго порядка по действиям в нормальной форме не сохраняется.

Коэффициенты ``d_k`` с тора не используют ``\eta`` и ``\xi``. Подстановка ``\delta_m^2=2\sigma_\delta^2 J_s`` в формулу выше их воспроизводит. На решётке нуклотронного типа при кинетической энергии дейтрона 270 МэВ два чтения согласуются с относительной точностью ``10^{-6}``:

|  | ``d_x`` [1/м] | ``d_y`` [1/м] | ``d_s`` [1/м] |
|---|---|---|---|
| среднее по тору | 0.14665244 | 0.22328941 | ``2.477064\times 10^{-3}`` |
| формула проскальзывания | 0.14665257 | 0.22328971 | ``2.477064\times 10^{-3}`` |

Интегрирование неразложенных гамильтонианов от элемента к элементу с точным тонким толчком даёт то же ``\delta_{\mathrm{eq}}`` с точностью до нескольких единиц в ``10^3`` при ``\delta_m\le 10^{-3}``. Остаток растёт как ``\delta_m^2`` (следующий порядок, не сохранённый). Формула — подгонка среднего по тору, а не независимая динамическая модель.

Средняя энергия получает ещё кинематический кусок от ``\langle\delta^2\rangle``:

```math
\Delta E_{\mathrm{eq}}
=\beta_s^2 E_s\Bigl(\delta_{\mathrm{eq}}+\frac{\delta_m^2}{4\gamma_s^2}\Bigr).
```

ВЧ в этом сравнении — тонкий энергетический толчок в одной точке кольца. Резонатор конечной длины имеет собственное смещение замкнутой орбиты по ``\delta``. Это смещение есть поток толстого резонатора, а не данное среднее.
