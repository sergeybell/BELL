# The s-Hamiltonian

The physics of an element is the scalar ``H(z,s)``. The vector field is not written first and then fitted by a Hamiltonian. It is ``\mathrm{d}z/\mathrm{d}s=S\nabla H``.

## From ``(t,-E)`` to ``(l,\delta)``

On a straight reference axis the pairs ``(x,P_x)``, ``(y,P_y)`` and ``(t,-E)`` are canonical, and the generator of motion in ``s`` is minus the longitudinal kinetic momentum, minus the charge times ``A_s``:

```math
\mathcal{H}
=-\sqrt{E^2/c^2-m^2c^2-(P_x-ZeA_x)^2-(P_y-ZeA_y)^2}-ZeA_s.
```

Time is counted from the reference particle, ``\Delta t=t-t_0(s)``, and momenta are divided by ``p_0``. The type-2 generating function

```math
F_2(t,P;s)=-p_0 c\,P\,\bigl(t-t_0(s)\bigr)
```

produces the new coordinate ``q=-c\,\Delta t`` and the new momentum ``P=E/(p_0 c)``, and it adds ``P/\beta_0`` to the Hamiltonian. After dividing by ``p_0``,

```math
H=\frac{P}{\beta_0}
-\sqrt{P^2-\frac{1}{\beta_0^2\gamma_0^2}-(p_x-a_x)^2-(p_y-a_y)^2}-a_s,
```

with ``a_i=(Ze/p_0)A_i`` and ``p_{x,y}=P_{x,y}/p_0``.

The momentum deviation ``\delta=(p-p_0)/p_0`` replaces the energy coordinate ``P``. Define the dimensionless energy

```math
\mathcal{E}(\delta)=\sqrt{(1+\delta)^2+\frac{1}{\beta_0^2\gamma_0^2}}=\frac{E}{p_0 c},
\qquad \mathcal{E}(0)=\frac{1}{\beta_0}.
```

The point transformation generated by ``F_2(q,\delta)=q\,\mathcal{E}(\delta)`` is

```math
P=\mathcal{E}(\delta),\qquad
l=q\,\frac{\mathrm{d}\mathcal{E}}{\mathrm{d}\delta}=q\,\beta(\delta)=-v\,\Delta t.
```

Because this ``F_2`` does not depend on ``s``, the value of ``H`` is unchanged: substitute ``P=\mathcal{E}(\delta)`` and ``q=l/\beta(\delta)``. Since ``P^2-1/(\beta_0^2\gamma_0^2)=(1+\delta)^2``,

```math
H=\frac{\mathcal{E}(\delta)}{\beta_0}-p_s-a_s,\qquad
p_s=\sqrt{(1+\delta)^2-(p_x-a_x)^2-(p_y-a_y)^2}.
```

## Energy term

``\mathcal{E}(0)/\beta_0=1/\beta_0^2`` is an irrelevant constant. Subtracting it defines the longitudinal term used by every magnetic element and by the thick cavity:

```math
\mathrm{energy\_term}(\delta)
=\frac{1}{\beta_0}\sqrt{(1+\delta)^2+\frac{1}{\beta_0^2\gamma_0^2}}-\frac{1}{\beta_0^2}.
```

On the reference orbit ``\mathrm{energy\_term}(0)=0``. It is not the kinetic energy. Differentiating under the square root gives the identity that fixes the sign of ``l``:

```math
\frac{\partial\,\mathrm{energy\_term}}{\partial\delta}=\frac{v(\delta)}{v_0}.
```

Check on a drift (``a=0``), on axis (``p_s=1+\delta``):

```math
\frac{\mathrm{d}l}{\mathrm{d}s}
=\frac{\partial H}{\partial\delta}
=\frac{v}{v_0}-1.
```

The same result follows from ``l=-v\Delta t`` and ``\mathrm{d}(\Delta t)/\mathrm{d}s=1/v-1/v_0`` when ``v`` is constant along the drift. The formula is evaluated on numbers, on a Taylor polynomial, and on a differential-algebra number by the same expression.

Curvature and the vector potential of each element are added in [Element Hamiltonians](hamiltonians.md). The constant and any linear piece are removed only when ``H`` is stored as the Lie-path polynomial, and a leftover linear piece means the reference orbit is not a solution.
